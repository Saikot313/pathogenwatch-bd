### 2.2 `NOTDEFINED` / `SENTINEL` / `NONSENTINEL` and double counting

A country-week may have rows from several sources. 41,289 rows share a country-week key with another row, so a naive `groupby(country, week).sum()` mixes sources. Combinations observed:

| source_combination | country_weeks |
|---|---|
| NOTDEFINED | 85617 |
| NONSENTINEL+SENTINEL | 38990 |
| SENTINEL | 19224 |
| NONSENTINEL | 3243 |
| NONSENTINEL+NOTDEFINED+SENTINEL | 951 |
| NONSENTINEL+NOTDEFINED | 180 |
| NOTDEFINED+SENTINEL | 136 |

Where `NOTDEFINED` co-exists with `SENTINEL`/`NONSENTINEL`, it is **not** reliably their sum:

| column | weeks_compared | notdefined_equals_sum | notdefined_greater | notdefined_smaller |
|---|---|---|---|---|
| SPEC_PROCESSED_NB | 1264 | 0.169 | 0.312 | 0.519 |
| INF_A | 864 | 0.344 | 0.196 | 0.461 |

**Policy applied (documented assumption):** if a `NOTDEFINED` row exists it is treated as the national total and used alone; otherwise `SENTINEL` and `NONSENTINEL` are summed. `NOTDEFINED` is never added to the others. The data cannot prove this is the intended semantics in every country, so affected weeks are flagged (`N_SOURCES_AVAILABLE`, `SOURCE_USED`); 40,257 country-weeks have more than one source available. Bangladesh has 0 such weeks, so the Bangladesh analysis is not affected by this ambiguity.

### 2.4 Logical consistency checks

| check | violations | rows_checked |
|---|---|---|
| INF_A != sum(A subtypes) | 110 | 158701 |
| INF_B != sum(B lineages) | 2187 | 162478 |
| INF_ALL != INF_A + INF_B | 0 | 96768 |
| INF_ALL > SPEC_PROCESSED_NB | 1067 | 99916 |
| INF_ALL + INF_NEGATIVE > SPEC_PROCESSED_NB | 1371 | 44873 |
| SPEC_PROCESSED_NB > SPEC_RECEIVED_NB | 2355 | 65813 |
| INF_ALL missing although INF_A/INF_B present (recoverable) | 60097 | 156865 |
| negative counts | 0 | 189549 |
| SPEC_PROCESSED_NB == 0 (no testing; not zero cases) | 28078 | 189549 |

- Rows violating `INF_ALL <= SPEC_PROCESSED_NB` or `processed <= received` are **flagged, not edited**; the source cannot tell us which field is wrong.
- `SPEC_PROCESSED_NB == 0` means no specimens were tested; positivity is undefined (NaN), not 0.

The final week (2026-10-05) is treated as **provisional** (processed < received in the source) and is excluded from alerting and evaluation.

## 3. Limitations

- FluNet is an aggregated, self-reported, sentinel-dominated dataset; changes in testing policy and site coverage change denominators.
- No lab-confirmed outbreak labels exist in this file.
- Columns for RSV, other viruses and comments were not audited beyond missingness.
